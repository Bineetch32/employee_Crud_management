# Employee CRUD Management

Angular application for managing employee records using CRUD operations and a REST API.

## Tech Stack

- Angular 19
- TypeScript
- Bootstrap 5
- RxJS
- Angular HttpClient

## Features

- Add employees
- View employees
- Update employees
- Delete employees
- Form handling
- REST API integration
- Responsive UI

## API

The application currently uses:

```text
http://localhost:3000/Employee
```

## Run Locally

```bash
npm install
ng serve
```

Open `http://localhost:4200/`.

## Build

```bash
ng build
```
